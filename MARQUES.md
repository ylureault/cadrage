Le **code** de ce dépôt est sous [licence MIT](LICENSE) : vous pouvez l'utiliser, le modifier et le redistribuer librement.

Les éléments suivants **ne sont pas** couverts par la licence MIT et restent la propriété d'Insuffle :

- les noms **Insuffle** et **Insuffle Académie**, leurs logos (`client/src/assets/`, `client/public/brand/`) et leur charte graphique ;
- la marque **Futur Désiré®** ;
- les contenus de méthode : modèles de déroulé (`server/src/templates.js`), bibliothèque de méthodes et repères (`client/src/planning/methods.js`, `client/src/planning/constants.js`, `client/src/planning/insuffle.js`), textes de l'interface qui décrivent la méthode Insuffle.

## Ce que vous pouvez faire

- Utiliser l'outil tel quel, y compris pour vos clients.
- Contribuer à ce dépôt, y compris sur les contenus de méthode : vos propositions sont les bienvenues.
- Réutiliser le code dans votre propre projet.

## Ce qu'on vous demande

Si vous déployez votre propre version publique, retirez le logo et le nom d'Insuffle, et ne présentez pas votre version comme un service d'Insuffle. Une ligne « basé sur le cadrage open source d'Insuffle » avec un lien vers ce dépôt fait plaisir.

Une question : [contact@insuffle.com](mailto:contact@insuffle.com).
